# 算法工坊 · Algo Lab

> 让算法，看得见。免费、零依赖的中文数据结构与算法可视化实验室。

在浏览器里逐步播放、暂停和回看算法的每一步：排序中的比较与交换、二分查找的区间折半、栈与队列的进出、二叉搜索树的插入与删除、广度优先搜索的逐层扩散。每一步都配有中文解说、状态变量、执行记录与高亮伪代码。

开源代码：<https://github.com/chalmery/algo-lab>

## 特性

- **8 个交互式演示**：冒泡 / 快速 / 归并排序、二分查找、二叉搜索树、栈、循环队列、广度优先搜索
- **逐步播放器**：播放、暂停、单步前进后退、时间轴拖动回看任意一步，速度 0.5×–4× 可调
- **同步讲解**：每一步的中文解说、状态变量（左右边界、基准、队头队尾……）、执行记录与当前伪代码行高亮
- **自由实验**：自定义输入数据（含完整校验）、一键随机数据、图的边集编辑，栈 / 队列 / 树支持连续操作演示
- **键盘与无障碍**：空格播放暂停、← → 单步、⌘/Ctrl K 全局搜索算法，跳转链接与完整 ARIA 标注
- **深浅色主题**：跟随系统并可手动切换记忆，`prefers-reduced-motion` 下自动停用位移动画
- **零依赖、零追踪**：无框架、无 npm 依赖、无任何第三方请求，CSP 限制 `connect-src 'none'`，数据不出浏览器
- **极致轻量**：全站 gzip 约 24 KiB，构建脚本强制 40 KiB 体积预算，静态资源内容指纹 + 永久缓存

## 算法目录

| 分类 | 算法 | 级别 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- | --- | --- |
| 基础结构 | 栈 | 入门 | O(1) | O(n) |
| 基础结构 | 队列（循环数组） | 入门 | O(1) | O(n) |
| 查找与索引 | 二分查找 | 入门 | O(log n) | O(1) |
| 查找与索引 | 二叉搜索树 | 进阶 | O(h) | O(n) |
| 排序算法 | 冒泡排序 | 入门 | O(n²) | O(1) |
| 排序算法 | 快速排序 | 进阶 | O(n log n) | O(log n) |
| 排序算法 | 归并排序 | 进阶 | O(n log n) | O(n) |
| 图算法 | 广度优先搜索（BFS） | 进阶 | O(V + E) | O(V) |

## 快速开始

需要 Node.js ≥ 22。项目没有任何 npm 依赖，克隆即可运行：

```bash
npm run dev     # 开发服务器 http://127.0.0.1:4173（直接服务 src/）
npm test        # 运行引擎测试（node:test，无需浏览器）
npm run build   # 构建到 dist/：内容指纹 + 体积预算检查
npm start       # 本地预览构建产物 dist/
```

## 项目结构

```
algo-lab/
├── src/
│   ├── index.html          # 单页应用骨架
│   ├── app.js              # 界面交互、播放器与 SVG 渲染
│   ├── engine.js           # 算法追踪：纯函数，输出不可变帧快照
│   ├── catalog.js          # 算法目录：元信息、伪代码与默认数据
│   ├── style.css           # 全部样式（含深色主题与响应式）
│   ├── _headers            # Cloudflare 安全头（CSP 等）与缓存策略
│   ├── 404.html            # 自定义 404 页面
│   └── favicon.svg
├── scripts/
│   ├── build.mjs           # 零依赖构建：统一指纹 + gzip/brotli 统计 + 40 KiB 预算
│   └── serve.mjs           # 本地静态服务器
├── tests/
│   └── engine.test.mjs     # 引擎测试
└── wrangler.jsonc          # Cloudflare 部署配置（静态资产目录 dist/）
```

核心设计：算法引擎与界面完全分离。`engine.js` 只产出「帧快照数组」——每个快照包含数据、高亮元素、状态变量与解说文案，算法运行期间不改写任何历史帧。播放器的播放、单步、回退、拖动时间轴只是移动帧索引，因此天然免费获得回看能力，测试也不需要浏览器。

## 新增一个算法

1. 在 `src/catalog.js` 注册：所属分组、名称、复杂度、伪代码、默认数据与 `kind`（渲染方式，现有 `sort` / `search` / `stack` / `queue` / `tree` / `graph`）。
2. 在 `src/engine.js` 实现追踪逻辑：每执行一个关键动作就 `emit()` 一帧（消息文案、伪代码高亮行、状态变量），保持帧不可变。
3. 若引入了新的 `kind`，在 `src/app.js` 添加对应的渲染函数并接入 `render()`，在 `operationControls()` 补充操作控件。
4. 在 `tests/engine.test.mjs` 补充测试。正确性、输入边界与「伪代码高亮行号不越界」均有现成断言模式可参考。

## 测试覆盖

`npm test` 使用 Node.js 内置测试器，覆盖：

- 三种排序在空数组、单元素、重复值、有序 / 逆序及 50 组随机数据上的排序正确性，且输入与历史帧不可变
- 二分查找的命中、未命中、重复值与空数组分支
- 栈与循环队列的空 / 满保护、先进先出与跨边界复用
- 二叉搜索树的插入、查找、拒绝重复，以及删除叶子 / 单子节点 / 双子节点 / 根节点 / 缺失值后的性质校验
- 广度优先搜索处理环、不连通图、队列去重与最短距离
- 数字与图输入解析的边界（中文逗号、越界、非法字符、孤立节点）
- 所有演示的伪代码高亮行号与目录声明一致

## 部署

纯静态站点，任何静态托管都可以，推荐 Cloudflare：

- **Pages Git 集成**：连接仓库，构建命令 `npm run build`，输出目录 `dist`。`src/_headers` 会随构建复制到 `dist/`，为全站提供安全头（CSP、nosniff、Referrer-Policy 等）与缓存策略（HTML 实时校验、带指纹资源永久缓存）。
- **Wrangler CLI**：`npx wrangler deploy`（配置见 `wrangler.jsonc`）。
- 未匹配路径会回退到 `dist/404.html` 自定义错误页。
